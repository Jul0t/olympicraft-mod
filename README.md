# Olympicraft

Olympicraft est une plateforme de mini-jeux configurable pour
Minecraft Java 1.21.1 avec Fabric.

## État actuel

Première fondation technique :

- initialisation côté serveur logique ;
- initialisation côté client ;
- commande `/oc` ;
- mode test de base ;
- structure prévue pour la configuration et les mini-jeux.

## Commandes disponibles

- `/oc`
- `/oc help`
- `/oc status`
- `/oc config reload`
- `/oc test enable`
- `/oc test disable`
- `/oc test status`

## Compilation

Le projet nécessite Java JDK 21.

Sous Windows :

```powershell
.\gradlew.bat build
```
